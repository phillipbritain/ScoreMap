# Planned game length and estimated end times

ESPN's scoreboard says when a game starts but not when it ended, was suspended, or was planned to end, yet pin windows depend on those times: a Final game keeps its pin for 2 hours after it ends, and a Disrupted game keeps the windows of its original schedule. So each league is configured with a `PlannedLength`, how long its games usually take, and the server works out the missing times itself. A game the server sees turn Final (or suspended) ended when it was first seen so. A game already Final (or suspended) the first time the server sees it, for instance after the server slept with no browser connected, gets an estimated end of its start plus `PlannedLength`, or now if that is still to come; otherwise old games would reappear for 2 hours every time the server woke. A postponed or canceled game is planned to end at its start plus `PlannedLength`. We accept that these estimates are wrong for long overtimes and short games, and that the game panel shows the estimate as the end time. A provider that reports real end times would make this unnecessary.
