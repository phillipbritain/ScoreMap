# Map fonts from fonts.openmaptiles.org

The globe's place names are written in Open Sans, so its fonts come from the free font server at fonts.openmaptiles.org rather than from OpenFreeMap, which serves the map tiles and style but only has Noto Sans. In October 2026 the place names looked off, and a prototype (branch `prototype-label-styles`) compared five looks on the live globe: the existing grey Noto Sans, a printed-atlas look, Montserrat, a dim Roboto look, and "warm night", cream Open Sans on a dark outline with muted gold state capitals. Warm night won. Only the fonts move: the tiles and the base style still come from OpenFreeMap. fonts.openmaptiles.org doesn't have plain Noto Sans (only "Klokantech Noto Sans"), so cluster counts are in Open Sans Bold too. We accept a second free service the globe depends on; if it goes away, the place names can return to Noto Sans from OpenFreeMap by changing `glyphsUrl` and the list of fonts it has, `globeFonts`, both in `web/src/theme/globeFonts.ts`, and the theme's globe fonts.

## Themes

Place names' colours, outlines and fonts now come from the theme (ADR-0011), per kind of place. The built-in dark theme's are no longer warm night's cream and gold but pale navy steps on a darker navy outline, so they sit quietly on its navy globe; they're still in Open Sans. A theme's globe text must use one of fonts.openmaptiles.org's fonts, listed in `globeFonts`: for a font it lacks, the server answers with a web page rather than an error, and the text falls back to a browser font, so checking a theme rejects any other font for text on the globe.
