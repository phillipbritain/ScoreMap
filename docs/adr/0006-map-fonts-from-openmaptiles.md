# Map fonts from fonts.openmaptiles.org

The globe's place names are written in Open Sans, so its fonts come from the free font server at fonts.openmaptiles.org rather than from OpenFreeMap, which serves the map tiles and style but only has Noto Sans. In October 2026 the place names looked off, and a prototype (branch `prototype-label-styles`) compared five looks on the live globe: the existing grey Noto Sans, a printed-atlas look, Montserrat, a dim Roboto look, and "warm night", cream Open Sans on a dark outline with muted gold state capitals. Warm night won. Only the fonts move: the tiles and the base style still come from OpenFreeMap. fonts.openmaptiles.org doesn't have every Noto Sans weight, so cluster counts are in Open Sans Bold too. We accept a second free service the globe depends on; if it goes away, the place names can return to Noto Sans from OpenFreeMap by changing `glyphsUrl` and the fonts in `globeStyle.ts` (including the CSS font `cityNameLook` measures names with) and `pinLayers.ts`.
