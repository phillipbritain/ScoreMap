# Real-browser tests for the globe map, against an injected local style

The globe map (`web/src/globe/globeMap.ts`) is tested in headless Chromium through Vitest's browser mode and Playwright, drawing on a tiny local style passed in by the tests: a background and nothing else, so no tiles, fonts or network. The map wiring (pins, clusters, score cards, selection, animations, slow spin) only means anything with MapLibre really running, which needs WebGL and a page, so mocking MapLibre or using jsdom would test our guesses about it rather than the map. The app passes OpenFreeMap's style made over by `globeStyle` instead; taking the style as an option is what lets the tests leave the network out. The price is a slower, heavier test run and Chromium to install, so these tests are kept to the globe map in a separate Vitest project: `npm test` stays the fast Node run, `npm run test:browser` runs them, and CI runs both. With no glyphs in the test style, cluster counts aren't drawn, so the tests look for the clusters rather than their numbers; the place names and the map's real look aren't covered, and are still checked by running the app.
