# Themes as checked JSON, with a palette worked out in OKLCH

ADR-0014 has since reshaped the theme as MUI's is: what this calls the palette (the base colors and their steps) is now the theme's `colors`, a `palette` says what they're for, and the settings are the typography, spacing, shape, statuses and components. What follows still holds of it.

ScoreMap's look comes from a theme: one JSON file, checked when it's loaded, that the code reads only through its resolved form (`web/src/theme/theme.ts`), so a new look can be dropped in without touching the code. The built-in theme is bundled into the app and resolved as it starts, so the first paint is themed with no wait on the network and no flash; a broken built-in theme fails its test rather than shipping. Checking lists every problem it finds (a missing setting, a color job naming a step the palette doesn't have, a globe font fonts.openmaptiles.org doesn't have, ADR-0006), not just the first. We chose JSON over a TypeScript object so a theme is plain data a later setting could load at runtime, and over CSS alone because the globe's map style and place names are drawn by MapLibre, which needs the values themselves, not CSS custom properties.

A theme has two layers. Its **palette** names a few base colors, and each base color's steps (100, lightest, to 900, darkest; 500 is the base) are worked out in OKLCH: evenly in lightness toward white one way and black the other, at the base color's hue, keeping its chroma or as much as sRGB can show. OKLCH because its lightness looks even and its hue doesn't drift as a color lightens, which mixing with white or black in sRGB, or HSL's lightness, does. Any single step can be hand-set where the worked-out one looks off. Its **settings** give every color job (the globe's surface, its lines, each kind of place name, and so on) a palette step by name, such as `navy.700`, so changing a base color changes every job that uses it. A color job may instead give a color directly, as the escape hatch for one-offs the palette doesn't fit (today's see-through white lines, say), at the cost of that color no longer following the palette.

## Consequences

- Adding a setting means adding it to the settings in `theme.ts` and to every theme's JSON; a theme without it is rejected.
- Steps are `#rrggbb`, so they work alike in CSS and in MapLibre's style. Colors given directly are passed on as written, so they must be ones both understand.
