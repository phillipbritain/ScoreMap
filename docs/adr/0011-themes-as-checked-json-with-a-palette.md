# Themes as checked JSON, with a palette worked out in OKLCH

ScoreMap's look comes from a theme: one JSON file, checked when it's loaded, that the code reads only through its resolved form (`web/src/theme/theme.ts`), so a new look can be dropped in without touching the code. The built-in theme is bundled into the app and resolved as it starts, so the first paint is themed with no wait on the network and no flash; a broken built-in theme fails its test rather than shipping. Checking lists every problem it finds (a missing setting, a colour job naming a step the palette doesn't have, a globe font fonts.openmaptiles.org doesn't have, ADR-0006), not just the first. We chose JSON over a TypeScript object so a theme is plain data a later setting could load at runtime, and over CSS alone because the globe's map style and place names are drawn by MapLibre, which needs the values themselves, not CSS custom properties.

A theme has two layers. Its **palette** names a few base colours, and each base colour's steps (100, lightest, to 900, darkest; 500 is the base) are worked out in OKLCH: evenly in lightness towards white one way and black the other, at the base colour's hue, keeping its chroma or as much as sRGB can show. OKLCH because its lightness looks even and its hue doesn't drift as a colour lightens, which mixing with white or black in sRGB, or HSL's lightness, does. Any single step can be hand-set where the worked-out one looks off. Its **settings** give every colour job (the globe's surface, its lines, each kind of place name, and so on) a palette step by name, such as `navy.700`, so changing a base colour changes every job that uses it. A colour job may instead give a colour directly, as the escape hatch for one-offs the palette doesn't fit (today's see-through white lines, say), at the cost of that colour no longer following the palette.

## Consequences

- Adding a setting means adding it to the settings in `theme.ts` and to every theme's JSON; a theme without it is rejected.
- Steps are `#rrggbb`, so they work alike in CSS and in MapLibre's style. Colours given directly are passed on as written, so they must be ones both understand.
