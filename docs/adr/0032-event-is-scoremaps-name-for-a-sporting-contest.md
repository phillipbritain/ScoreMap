# Event is ScoreMap's name for a sporting contest

ScoreMap tracks games and matches alongside races, golf tournaments, and fight cards. Use **event** for the unit visitors follow on the globe, including in labels, accessibility text, and the glossary (#466). The browser, feed adapter, and API contracts use the contest model and implementation terminology from [ADR-0020](0020-games-with-a-field-or-a-fight-card.md), including `Game` and `ProviderGame`.
