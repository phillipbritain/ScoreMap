# Triage labels

ScoreMap uses the triage skill's default labels, under the same names:

| Label | Meaning |
| --- | --- |
| `needs-triage` | The maintainer needs to evaluate this issue |
| `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | Fully specified, ready for an agent to work on alone |
| `ready-for-human` | Needs a person to implement it |
| `wontfix` | Won't be acted on |
